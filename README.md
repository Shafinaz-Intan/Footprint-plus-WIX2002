# Footprint-plus-WIX2002
Footprint+: a UM campus walking app that tracks walking trips, estimates CO₂ saved compared with driving, and rewards students for reaching step goals. WIX2002 group project, Sem 1 2026/2027.

## Working rules
1. Do not edit the `main` branch directly.
2. Create your own branch for each task (e.g. `frontend-setup`).
3. Open a pull request when done and ask one teammate to review it.
4. Write short, clear commit messages (e.g. "Add trips table draft").
